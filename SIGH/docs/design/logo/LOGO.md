# Logo do SIGH

Vetorizado a partir de `referencia-logo-original.png`, a imagem aprovada pelo dono do produto. Desenho, símbolo e fonte são os do original: tudo está convertido em curvas (paths), então não depende de nenhuma fonte instalada. Não redesenhe nem troque por texto com fonte parecida.

| Arquivo | Uso |
|---|---|
| `sigh-logo-para-fundo-escuro.svg` | Escudo + "SIGH" em branco. Menu lateral no tema escuro |
| `sigh-logo-para-fundo-claro.svg` | Escudo + "SIGH" em azul-marinho (#0B1F44). Menu lateral no tema claro |
| `sigh-logo-completo-para-fundo-escuro.svg` | Escudo + "SIGH" + "Sistema Inteligente de Gestão de Histórico Disciplinar". Tela de login (painel escuro) |
| `sigh-logo-completo-para-fundo-claro.svg` | O mesmo, para fundo claro (login no celular com tema claro) |
| `sigh-simbolo.svg` | Só o escudo. Menu recolhido, avatar do sistema, favicon |
| `favicon/` | favicon.ico (16 e 32), PNG 32, 180 (apple-touch-icon) e 512 |

Cores do escudo: duas tonalidades separadas por uma linha vertical no centro, como no original.
- Metade esquerda: degradê vertical de #0BB4FD a #047EF8.
- Metade direita: de #0274FE a #0062FE.

Use #0BB4FD e #0062FE como referência para a cor de destaque do tema.

Proporções: nunca distorça; altere só a altura e deixe a largura acompanhar. Altura mínima do logo horizontal: 28 px. Abaixo disso, use só o símbolo.
